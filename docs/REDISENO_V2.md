# Diferencias con la primera versión

1. **Hero:** sustituyó dientes geométricos laterales por sonrisa fotográfica de fondo con alineador transparente y filamentos tridimensionales sutiles.
2. **Composición:** tarjeta de beneficios superpuesta; jerarquía y densidad similares a las maquetas.
3. **Contenido:** problema del paciente → alternativa clínica → Colombia → tratamientos → resultados → trayectoria → doctora → orientación virtual → proceso → fotografías → historias → FAQ → formulario.
4. **Colombia:** tres recursos visuales independientes y locales, no recortes de maquetas. Son composiciones ilustrativas inspiradas en lugares reales, no fotos documentales.
5. **Resultados:** comparador funcional etiquetado como demostración, sin representar resultados falsos.
6. **WhatsApp:** el formulario permite construir un mensaje para +57 311 644 5913; no almacena información ni lo envía hasta que el visitante confirma en WhatsApp.
7. **Móvil:** menú desplegable, hero vertical con fotografía destacada y formulario en una sola columna.
8. **SEO:** noindex por ser prototipo; deberá cambiarse solo al validar contenidos, autorización de imágenes y privacidad.
